# Mémoire commune des agents — MakeMeLearn (jeu d'apprentissage multi-univers)

Protocole (tous les agents) :
1. LIRE d'abord tout `dossier/memory/*.md` (sauf si vide) avant de commencer.
2. ÉCRIRE tes livrables dans `dossier/research/<ton-role>.md` (un fichier par agent, structuré, sourcé, concret).
3. AJOUTER tes faits clés / décisions dans `dossier/memory/FACTS.md` : 1 ligne = `- [role] fait ou décision (source/confiance)`. Append uniquement, ne jamais réécrire les lignes des autres.
4. Questions ouvertes pour les autres : `dossier/memory/OPEN_QUESTIONS.md` (même format append).
5. Tu peux lancer toi-même des sous-agents (outil Agent) pour paralléliser des recherches ; donne-leur ce même protocole.
6. Langue des livrables : français. Contexte projet : landing makemelearn.fr (communauté d'autodidactes), stack HTML/CSS/JS statique + API Express4/Postgres, déployé sur VPS via Docker+Traefik. Objectif : le transformer en jeu d'apprentissage multi-univers ultra addictif (boucle d'engagement saine, pas de dark patterns manipulateurs).
